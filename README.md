# RainDrop
A simple, straightforward way to share links and images across devices on the same local network. No setup required, no clutter, and completely local. IP not required.

![banner](screenshots/raindropbanner.png)

Only available in Brazilian Portuguese!!

# What is it?
RainDrop exists because sending a quick link or image to another device nearby is usually annoying. Instead of opening a browser, logging into accounts, or messaging yourself on chat apps, RainDrop sits quietly in your system tray, automatically finds devices around you, and handles peer-to-peer transfers directly.

# Features
* Auto-Discovery: Scans the local network and gateway routes to find available devices instantly without manual IP configuration.
* Links & Images: Share text links or images with a clean, lightweight interface.
* Background Tray Integration: Stays out of your way in the system tray so it is always ready when you need it.
* Zero-Config: Pure python script, lightweight and portable.

# How to Run
Make sure you have Python installed along with the required dependencies (customtkinter, tkinter, pystray and Pillow).
Download the latest release and run:

```python raindrop.py```
